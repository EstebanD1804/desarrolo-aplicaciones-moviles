# Desarrollo de Aplicaciones Móviles

Repositorio de prácticas y proyectos de la materia Desarrollo de Aplicaciones Móviles.

## Tecnologías

- Kivy con Python
- Android Studio
- Xcode

## Comandos para hacer commit en Git
git status
git diff 
git add add Kivy/tema1/ejemplo.py
git commit -m "Agrega descripcion del commit"
git push

## Para guardar todos los cambios de Kivy
git add Kivy/
git commit -m "Agrega descripcion del commit"
git push

## Para guardar todos los cambios del repositorio
git add .
git commit -m "Agrega descripcion del commit"
git push
